# Image-captioning-using-CNNs-LSTMs--Deep-Learning-project

<b>Image Captioning using CNNs & LSTMs</b>

This project implements an Image Captioning System using Deep Learning techniques. The model combines CNNs (Convolutional Neural Networks) for image feature extraction and LSTMs (Long Short-Term Memory networks) for generating meaningful captions from images.

<b>Features</b><br>
Image feature extraction using CNN models<br>
Caption generation using LSTM networks<br>
Text preprocessing and tokenization<br>
Training pipeline for image-caption datasets<br>
Visualization and prediction support<br>


<b>Technologies Used</b><br>
Python<br>
TensorFlow / Keras<br>
NumPy<br>
Pandas<br>
Matplotlib<br>

<b>Project Workflow</b><br>
Load and preprocess image-caption dataset<br>
Extract image features using CNN<br>
Preprocess caption text<br>
Train LSTM-based caption generator<br>
Generate captions for unseen images<br>


<b>Files</b><br>
caption it.ipynb → Main implementation notebook<br>
Image-captioning-using-cnns-lstms.ipynb → Training and modeling notebook<br>
